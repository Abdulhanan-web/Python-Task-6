# 🐍 PDF Report Generator

## 📌 Overview

The PDF Report Generator is a Python-based CLI application that allows
users to input, manage, and generate professional PDF reports for
students or company employees.

This project simulates real-world reporting systems used in businesses
and educational institutions.

------------------------------------------------------------------------

## 🎯 Features

### 🔹 Data Input

-   Add data manually via CLI
-   Load data from CSV and JSON files

### 🔹 PDF Generation

-   Generate structured PDF reports using reportlab
-   Includes title, date & time, and tabular data

### 🔹 Report Types

-   Student Report
-   Company Report

### 🔹 File Saving

-   Auto-generates unique filenames
-   Saves reports in /reports folder

### 🔹 CLI Menu

-   Add Data
-   Load Data
-   Generate Reports
-   Exit

------------------------------------------------------------------------

## 🛠 Technologies Used

-   Python 3
-   ReportLab
-   CSV & JSON
